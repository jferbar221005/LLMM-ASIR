Bienvenido a mi página

Este es un ejemplo de diseño web adaptativo usando Flexbox y media queries. El contenido principal se muestra aquí. Puedes agregar artículos, imágenes, o cualquier información relevante.

¿Por qué usar diseño responsive?

  • Mejor experiencia en móviles y tablets.
  • Se adapta a cualquier tamaño de pantalla.
  • Es recomendado por los motores de búsqueda.

Prueba a cambiar el tamaño de la ventana para ver cómo se adapta el diseño.
