HTML

Introduccion

Introducción HTML, siglas en inglés de HyperText Markup Language (‘lenguaje de marcas de hipertexto’), hace referencia al lenguaje de marcado
para la elaboración de páginas web. Es un estándar que sirve de referencia del software que conecta con la elaboración de páginas web en sus diferentes
versiones, define una estructura básica y un código (denominado código HTML) para la definición de contenido de una página web, como texto,
imágenes, videos, juegos, entre otros.
Primeras especificaciones

Tim Berners-Lee

En 1991 describe 18 elementos que incluyen el diseño inicial y relativamente
simple de HTML. Trece de estos elementos todavía existen en HTML 4.
