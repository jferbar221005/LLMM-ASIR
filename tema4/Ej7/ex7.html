XML Standard Questions

Answers based on the XML 1.0 W3C Recommendation

1. What do comments look like in XML? (Section 2.5)

Comments in XML are enclosed with <!-- and -->.

<!-- This is an XML comment -->

2. Can an attribute be repeated in the same element? (Section 3.1)

No, an attribute cannot be repeated in the same element.

Each attribute name must be unique within an element. The standard states: "No attribute name may appear more than once in the same start-tag or empty-element tag."

<example attr="value" attr="another"> <!-- INVALID -->
<example attr="value" other="another"> <!-- VALID -->

3. Where is it stated that the element names in opening and closing tags must match?

The requirement that element names in opening and closing tags must match is stated in the section about "Start-tags, End-tags, and Empty-element Tags" (Section 3.1).

The standard says: "The Name in the end-tag MUST match the element type in the start-tag."

<example>...</example> <!-- VALID -->
<example>...</notexample> <!-- INVALID -->
