EJ1 XML SYNTAX

1. Elemento llamado "test element" con contenido

El elemento se llama test element y contiene el texto:
"This is our first element!"

<test element>This is our first element!</test element>

2. Jerarquía del elemento "book" con subelementos

El elemento book contiene los subelementos chapters y author.
El elemento author contiene name y address.

<book>
    <chapters></chapters>
    <author>
        <name></name>
        <address></address>
    </author>
</book>

3. Elemento "entry" con dos atributos

El elemento entry tiene dos atributos:
no con valor "24" y date con valor "27.10.2004".

<entry no="24" date="27.10.2004"/>

También puede escribirse con contenido interior (si lo tuviera):

<entry no="24" date="27.10.2004"></entry>
